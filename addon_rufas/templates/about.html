Como iniciar

Na raiz do repositório, instale as dependências e execute:

pip install -r requirements.txt
PYTHONPATH=.:RufSas/RuFaS python -m addon_rufas.web

Depois, abra http://127.0.0.1:5000 no navegador.

O que o sistema faz

O frontend carrega os 175 alimentos da biblioteca NASEM. Os alimentos da fazenda fictícia Midwest começam selecionados, mas qualquer alimento pode ser pesquisado, selecionado, desmarcado e editado.

O usuário pode alterar os dados da vaca, as exigências nutricionais, os custos e os limites de inclusão dos alimentos. A formulação procura uma ração de menor custo que atenda às restrições informadas.

Fluxo dos dados da vaca

Os dados individuais são enviados à calculadora original do RuFaS:

dados da vaca
  -> NASEMRequirementsCalculator.calculate_requirements
  -> funções de cada nutriente
  -> NutritionRequirements
  -> RationOptimizer ou LinearRationOptimizer
  -> ração otimizada

Depois do cálculo, as exigências continuam editáveis. Portanto, é possível usar os valores NASEM calculados ou testar valores definidos manualmente.

Otimizadores

Programação linear sequencial (SLP)

Usa LinearRationOptimizer, criado no add-on, e scipy.optimize.linprog com HiGHS. As restrições não lineares são linearizadas localmente e o problema linear é resolvido em passos sucessivos.

RuFaS original (SLSQP)

Usa RationOptimizer e scipy.optimize.minimize(method="SLSQP"). Nesse modo, a interface chama a implementação original sem alterá-la.

Para uma comparação justa, mantenha iguais os alimentos, preços, limites, exigências e peso corporal. Compare custo, viabilidade, ingredientes, quantidade de matéria seca, iterações e margens.

Preservação do RuFaS

Os arquivos em RufSas/RuFaS são usados como referência e permanecem sem alterações. O frontend está em addon_rufas/web.py, com templates em addon_rufas/templates/ e estilos em addon_rufas/static/.

A escolha entre os otimizadores acontece somente em tempo de execução.

Observações sobre os resultados

O SLP usa um ponto inicial determinístico. O otimizador original pode usar um ponto inicial aleatório quando não existe uma ração anterior; por isso, pequenas diferenças entre execuções do SLSQP são esperadas.

Na tabela de resultados, margem maior ou igual a zero indica que a restrição foi atendida.
